# CommTester

Портативный диагностический прибор линий связи и протоколов.

## Текущий этап

Сейчас разрабатывается первая компактная версия тестера **Modbus RTU / RS-232** на **Arduino Nano / ATmega328P**. Nano используется как ограниченная по ресурсам платформа для сохранения и проверки базовых функций.

В дальнейшем планируется заменить MCU на более производительный и развить этот же CommTester до полной конфигурации с Modbus Master, Slave, SERVICE/PING-PONG и расширенной диагностикой. Выбор будущего MCU пока не сделан.

## Текущая конфигурация Nano

- Arduino Nano / ATmega328P
- RS-232 через MAX238
- 9600 8N1
- один физический SoftwareSerial для RS-232
- режимы SERVICE / SLAVE
- RX / TX / ERROR / MODE LED
- пьезоизлучатель
- кнопка переключения режима
- дисплей пока не подключён

### SERVICE

- PING → PONG
- INFO
- MODE
- HELP

### Modbus Slave

Реализованы и протестированы:

- FC01 — Read Coils
- FC02 — Read Discrete Inputs
- FC03 — Read Holding Registers
- FC04 — Read Input Registers
- FC05 — Write Single Coil
- FC06 — Write Single Register
- FC15 — Write Multiple Coils
- FC16 — Write Multiple Registers

Память Coils и Discrete Inputs хранится в упакованном виде по битам, что позволяет использовать до 125 логических элементов без расхода SRAM как у `bool[125]`.

Holding/Input Registers используют `uint16_t`, по 2 байта на регистр.

### Что отложено на Nano

Modbus Master исключён из активной прошивки Nano из-за ограничений Flash/SRAM и необходимости выделить ресурсы под интерфейс. Это временное ограничение платформы, а не отказ от функции: Master планируется вернуть при переходе на более производительный MCU.

## Дисплей

Рассматриваются два варианта:

- OLED 128×64 — предпочтительный, если удастся обеспечить достаточный запас SRAM с использованием страничного буфера.
- LCD 1602A — резервный вариант. Он способен показывать режим, адрес, функцию, состояние обмена, ошибки и короткие значения. Для подробной информации потребуются несколько экранных страниц; весь пакет и все его поля одновременно на 16×2 символах не поместятся.

Окончательный выбор — после измерения памяти и проверки макета.

## Тесты

В каталоге `tests/` находятся Python-тесты для:

- полного набора Modbus-функций;
- CRC;
- межбайтовых интервалов;
- границы t1.5.

Тесты рассчитаны на подключение стенда к ПК через COM-порт и Python `pyserial`.

## Архитектура Nano

```text
CommTester_Bench.ino
        |
        +-- serial_console (SERVICE / PING-PONG)
        |
        +-- indicators
        |
        +-- modbus_slave
        |       |
        |       +-- modbus_slave_logic
        |
        +-- modbus_rtu
                |
                +-- ModbusADU (внешняя библиотека)
```

Modbus Master отсутствует в активном дереве прошивки Nano. Его исходная реализация сохранена в истории Git и может быть восстановлена для будущей платформы.

Проектный принцип: внешние библиотеки не изменяются; собственная логика проекта находится в исходниках CommTester.
